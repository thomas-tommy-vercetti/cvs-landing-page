# Enhanced CVS Landing Page

Responsive landing page built with React, Vite, Tailwind CSS, and Lucide React SVG icons.

## Run locally
Requires Node.js and npm.

```bash
npm install
npm run dev
```

Open the local URL printed by Vite, usually http://localhost:5173.

## Production build

```bash
npm run build
npm run preview
```

## Customize
- `src/main.jsx`: sections, features, use cases, workflow, comparison table, and links.
- `src/styles.css`: Tailwind directives and small custom styles.
- Replace `hello@example.com` and Brand Alpha placeholders before publishing.
- The throughput figures are project estimates, not independently validated benchmarks.
